A token launch radar for the [make.fun token-radar-01 competition](https://make.fun/bounty/token-radar-01). The program (`main.ts`, Node 22) reads the sealed DefiLlama snapshot, finds the protocols that record no token, ranks them by implied launch value with a comparable mcap/TVL model, and writes a static dashboard: the ranked board, a detail view for every protocol, a filter, and the steps to farm each one.
